## Evidencia y fuentes

Cada referencia de ejemplo tiene caso, fecha, revisión, ubicación y contenido inspeccionable. El visor separa el pasaje de la interpretación y conserva PPP/compositor. Comentar este dato prepara una referencia, sin enviar automáticamente ni guardar negocio. Una fuente ausente o de otro caso no devuelve contenido y propone preparar una búsqueda dentro del expediente actual.

Las cifras TIR se leen como datos precargados de una maqueta de un periodo: flujo normalizado t0=-100 y t1=115/118/120, TIR anual del proyecto 15/18/20%. Todos comparten horizonte y revisión. No existe motor financiero nuevo en el navegador. El modelo real conserva el contrato CTR-PPP-SHEETS y la fuente canónica del libro privado. Ausencia de evidencia o periodo muestra TIR no calculada; cero real se conserva como cero.
