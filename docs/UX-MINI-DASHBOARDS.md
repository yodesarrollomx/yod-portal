## Alcance

Esta versión revisa la maqueta del puesto y conserva el control global existente. No activa micrófono, ejecutor, supervisor o automatizaciones; no cambia registros, fórmulas, permisos, credenciales ni interfaces privadas. Los datos son ficticios, identificados en la pantalla, y se cargan desde archivos locales. Publicar esta maqueta no acredita integración operativa del agente.

## Antes → después y motivo

- La muestra gráfica de barra expandida se interpretó como otra barra a derecha. Se retira. Sólo queda navegación global a izquierda y PPP a derecha.
- Pestañas que reemplazaban el PPP → tablero persistente. Fuente/contexto y conversación comparten centro, con compositor conservado.
- Tarjetas genéricas → mapa ilustrativo, documentos clicables, normativa con pasajes resaltados y análisis separado, mercado con unidad/fecha/estudio, versiones y viabilidad dependiente de consulta.
- Audio y texto separados por ubicación → un hilo, una referencia de contexto y un compositor. En la maqueta el micrófono no se activa.
- Supuesta mejor alternativa por porcentaje → comparación de tipo, periodo, revisión y riesgo. V3 tiene mayor TIR ficticia y sigue no defendible por normativa pendiente; V2 defendida no cambia al consultar otra.

## Evidencia y fuentes

Cada referencia de ejemplo tiene caso, fecha, revisión, ubicación y contenido inspeccionable. El visor separa el pasaje de la interpretación y conserva PPP/compositor. Comentar este dato prepara una referencia, sin enviar automáticamente ni guardar negocio. Una fuente ausente o de otro caso no devuelve contenido y propone preparar una búsqueda dentro del expediente actual.

Las cifras TIR se leen como datos precargados de una maqueta de un periodo: flujo normalizado t0=-100 y t1=115/118/120, TIR anual del proyecto 15/18/20%. Todos comparten horizonte y revisión. No existe motor financiero nuevo en el navegador. El modelo real conserva el contrato CTR-PPP-SHEETS y la fuente canónica del libro privado. Ausencia de evidencia o periodo muestra TIR no calculada; cero real se conserva como cero.
