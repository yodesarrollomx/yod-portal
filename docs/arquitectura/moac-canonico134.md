# MOAC nativo en el despacho

Metas, objetivos y acciones conservan sus hojas y motores. El autón consulta su relación por ID y registra evidencia para revisión; una entrega no cambia la aprobación ni el estado de negocio.

El12-oct-2026 UTC se contrastaron Operación v23, Metas v5 y Portero v92 mediante API y respaldos privados. HEAD y las versiones publicadas coinciden. Identificadores físicos, credenciales y respaldos permanecen privados.

La propuesta comparte proyección por proyecto entre chat, voz y trabajador. Operación añadirá recibos ligados a la acción existente, con autorización fresca, revisión, bloqueo, idempotencia y conciliación. La ficha MOAC mostrará esas entregas. Una vinculación ausente o ambigua necesita una decisión de asignación; no se resuelve por similitud de nombres.

Pruebas aisladas, publicación de fuente y aceptación operativa se acreditan por separado. No se reactiva el supervisor cancelado.
