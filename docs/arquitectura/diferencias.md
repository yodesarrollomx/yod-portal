# Diferencias que requieren contraste

Estas observaciones pertenecen a la fotografía de fuentes del 2026-09-30. No deben resolverse copiando configuración antigua sobre un despliegue vigente.

## DOC-01 · SYS-YOD-OS

El documento de portal conserva pendientes de permisos que el expediente declara cerrados; su vigencia exige cotejo por versión.

Tratamiento: Registrar fecha, commit y deployment que sostienen cada decisión; no reabrir cambios antiguos automáticamente.

## DOC-02 · SYS-FLUJO

README mantiene instrucciones de nueva implementación y reconexión pendiente; estas instrucciones pueden desalinear URL y backend actual.

Tratamiento: Separar instalación inicial de actualización y describir despliegue real después de comprobarlo.

## DOC-03 · SYS-INVERSION

README lista carpeta backend como parte del repositorio, pero CLAUDE prohíbe versionarla y el árbol actual no la contiene.

Tratamiento: Marcar README histórico o actualizarlo con fuente real y procedimiento de promoción.

## DOC-04 · SYS-CODES-PORTAL

El tablero central espera resumenPublico, mientras el despachador versionado del backend no incluye esa acción.

Tratamiento: Obtener fuente desplegada y decidir contrato agregado mínimo con autorización adecuada; no copiar credencial administrativa al front.

## DOC-06 · SYS-SALA

README describe operación desde Mac mientras instrucciones más nuevas migran la producción a Actions; frecuencias actuales deben leerse de workflows.

Tratamiento: Documentar flujo de nube, compuertas y motores habilitados; separar historia de operación vigente.
