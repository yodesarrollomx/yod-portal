# Jarvis: consulta desde el grafo original

Propuesta autorizada 16-nov-2026. Evidencia: el usuario abrió `jarvis/data/06_yod.html`; su captura muestra comunidades numeradas sin acceso a miembros ni código. Terminado significa poder pasar de un grupo a sus archivos, de un archivo a sus funciones y de una función al texto local y la línea, además de entender flechas y estado.

La navegación compartida se carga desde las ocho URL nativas y desde `jarvis/`. Conserva el JSON nativo y sus comunidades/IDs. Las etiquetas se derivan de rutas y símbolos, con nombres de áreas explicativos. Un enlace es evidencia estática, no salud de servicios. Se limita el número dibujado y se conserva acceso a los resultados por lista y búsqueda.

Las fuentes no se publican. El propietario puede elegir un archivo o una carpeta local en el selector del navegador. Sólo se leen rutas del manifiesto dentro de esa carpeta, sin recorrerla. No se solicitan permisos de escritura, no se persisten fuentes y no se envía texto por red. El código se muestra como texto, nunca se ejecuta HTML; su SHA256 indica si coincide con la versión del grafo. Si cambió, las líneas pertenecen al corte y se advierte la diferencia. Cancelar o denegar conserva el visor funcional. En marcos que impidan el selector se ofrece abrir en grande.

Comprobaciones: navegación por ratón y lista, función/relaciones, historial, búsqueda, fuentes iguales/distintas, privacidad del tráfico, errores y móvil. Despliegue mediante PR y comparación de archivos servidos. Reversión: revertir sólo el PR; los datos del corte y el monitor no cambian.

Implementado y comprobado localmente: clic real sobre canvas, navegación por lista, historial, búsqueda de símbolos, todos los archivos del manifiesto, área de 35,444 nodos, rechazo de descarga fallida y móvil a 390 px. El lector distingue huella igual, modificada, archivo equivocado y línea fuera de rango. Los datos sintéticos con HTML activo se muestran como texto; no se ejecutan ni aparecen en peticiones. El permiso de carpeta es personal y de sólo lectura. No se añade servidor local ni se publica el código de Jarvis.

Revisión del cambio: los nodos/JSON y sus hashes permanecen intactos; los ocho HTML de exportación previa se conservan byte por byte como `*-original.html`. El generador repetible conecta las ocho direcciones anteriores al visor compartido. Riesgos revisados: archivo cruzado por URL, cambios de área mientras descarga, reporte inválido/vencido, fuente enorme/binaria y rutas inseguras. Sin dependencias nuevas; vis-network existente se conserva. Falta de relación y estado desconocido se presentan explícitamente.
