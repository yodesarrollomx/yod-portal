# Bandeja del Despacho en nube

Dirección autorizó continuar el11-oct-2026. La Bandeja existe en el Sheet de Operación; EJECUTOR.md documenta una rutina Claude cada hora. Se prepara un ejecutor Google Apps Script dedicado cada cinco minutos con Gmail por API y redacción por uso. No necesita una sesión de Claude o ChatGPT abierta.

La instalación inicia en observación. Antes de activar hay que confirmar el libro efectivo, autorizar Google bajo Dirección, comprobar dos ciclos y detener sólo la rutina antigua de Bandeja. No modificar el backend de Operación sin identificar su fuente activa. Los datos permanecen en el mismo Sheet y Gmail.

Una huella une borrador, contenido y destinatarios a la aprobación. Los registros heredados sin huella vuelven a revisión. Toda llamada de envío se reserva antes en almacenamiento privado; una respuesta incierta se concilia sin repetirla. Enviar no cierra una tarea cuya respuesta sigue pendiente.

Gmail, libro, redacción, programador y envío tienen pruebas separadas. La publicación de código y las pruebas sintéticas no acreditan un correo entregado. Gmail y Sheets no ofrecen una transacción conjunta; la relectura reduce la ventana de carrera y cualquier resultado incierto queda explícito.
