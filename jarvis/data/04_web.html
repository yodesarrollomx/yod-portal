Qué muestra este mapa y cómo leer el código

Los grupos y conexiones proceden del JSON original de Graphify. Sus nombres combinan el archivo principal y un símbolo del grupo; son etiquetas de navegación, sin alterar las comunidades calculadas por Graphify. Cada tarjeta indica cuántas piezas contiene el grupo. Una flecha prueba una relación estática; no que un servicio esté funcionando.

El código privado se lee desde una carpeta o archivo que elijas, sólo en este navegador. No se sube, no se ejecuta y no se guarda al cerrar. Su huella se compara con el corte; las líneas pueden cambiar si modificaste el archivo. Conecta la carpeta del proyecto o del archivo que quieras consultar.

El monitor revisa cambios cada cinco minutos mientras el equipo está encendido. Un área nueva requiere ampliar el inventario; las conexiones entre lotes son parciales.
