Procedencia, cobertura y límites

El mapa de archivos resume las relaciones del grafo nativo. Los ocho JSON contienen todos sus nodos y aristas. El visor nativo agrupa los grafos grandes para no saturar el navegador.

Se analizó código instalado, incluyendo JavaScript extraído de HTML con referencia al archivo y línea original. CSS se inventaría por huella; no se le atribuye análisis semántico. Se excluyen credenciales, datos, sesiones, dependencias vendorizadas y archivos de prueba según el manifiesto. La resolución entre lotes es parcial: no se afirma que todas las llamadas dinámicas estén resueltas.
